# Northlight Studio website

The Northlight Studio website: the studio home page and a page for each project.

| Page | File |
|---|---|
| Home, `/` | `site/index.html` |
| Barricade, `/barricade` | `site/barricade/index.html` |
| Barricade download, `/barricade/download` | `site/barricade/download/index.html` (holding page until the signed installer exists) |
| Pulse, `/pulse` | `site/pulse/index.html` (coming soon) |
| Runway, `/runway` | `site/runway/index.html` (in the works) |
| Cosmopolis, `/cosmopolis` | `site/cosmopolis/index.html` (in the works; `/lyceum` redirects here) |
| Let's Go, `/lets-go` | `site/lets-go/index.html` (in the works) |
| Parcel, `/parcel` | `site/parcel/index.html` (in the works) |
| About, `/about` | `site/about/index.html` |

The look is direction A, Calm, from round 2 of the website mocks. The pages share a header with
tabs, so they're generated by `tools/build_pages.py`: edit them there, run it, and commit `site/`. The picture of
each app (Barricade's window, a phone for each iPhone app) is drawn in `tools/pictures.py`, always with sample data.

## Develop

Plain HTML and CSS, no build step. To preview:

```bash
python3 -m http.server 8000 --directory site
```

Vercel serves `site/` as configured in `vercel.json`, with clean URLs (`/barricade` serves
`site/barricade/index.html`) and security headers.

`./ci.sh` runs every check, exactly as CI does on the Mac mini for each pull request and push to
`main`.

Started with `new-project` from [northlight-studio/dev-tools](https://github.com/northlight-studio/dev-tools).
